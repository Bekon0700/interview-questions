# DSA & Practical Coding — Questions

Two tracks: classic DSA warm-ups and practical JS machine-coding tasks that top companies use for frontend/full-stack roles. Try to solve before checking answers.

---

## Track A: DSA fundamentals

### Beginner
1. Reverse a string / check if a string is a palindrome.
2. Find the maximum/minimum in an array. What is time complexity?
3. Check if two strings are anagrams.
4. Remove duplicates from an array.
5. FizzBuzz.
6. What is Big-O notation? Give examples of O(1), O(n), O(log n), O(n^2).

### Intermediate
7. Two Sum — find two numbers that add to a target. (extremely common — Amazon, Google)
8. Find the first non-repeating character in a string.
9. Group anagrams together.
10. Valid parentheses (balanced brackets) using a stack.
11. Merge two sorted arrays / linked lists.
12. Maximum subarray sum (Kadane's algorithm).
13. Move all zeros to the end of an array (two pointers).
14. Find duplicates in an array in O(n) time.

### Advanced
15. Longest substring without repeating characters (sliding window). (commonly asked at Amazon)
16. Explain and implement a debounce-based typeahead search.
17. Binary search on a sorted array; discuss edge cases.
18. LRU cache — design and implement. (commonly asked at Amazon, Meta)
19. Given an array of tasks with dependencies, determine execution order (topological sort).
20. Two-pointer: container with most water / trapping rain water (conceptual).

## Track B: Practical JS machine-coding (very common for FE/full-stack)

21. Implement `debounce`. (your CV: relevant to request queueing)
22. Implement `throttle`.
23. Implement a deep clone.
24. Implement `Promise.all` from scratch.
25. Implement a promise-based concurrency limiter / promise pool. (your CV)
26. Implement an EventEmitter (on/off/emit/once).
27. Implement `flatten` for a deeply nested array.
28. Implement `memoize`.
29. Implement `curry`.
30. Implement `retry` with exponential backoff for a failing async function. (your CV: webhooks/retries)
31. Implement a function that groups an array of objects by a key (`groupBy`).
32. Implement `Array.prototype.map` / `reduce` polyfills.
