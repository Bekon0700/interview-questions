# Testing — Questions

Your CV doesn't mention testing, so interviewers may probe it. Be ready to show you understand the fundamentals.

---

## Beginner

1. Why is automated testing important? What does it give you beyond manual testing?
2. What is the difference between unit, integration, and end-to-end (e2e) tests?
3. What is the testing pyramid?
4. What is a mock, a stub, and a spy?
5. What is the AAA (Arrange-Act-Assert) pattern?
6. What is code coverage and is 100% coverage a good goal?

## Intermediate

7. How do you write a unit test in Jest? What do `describe`, `it`, `expect`, `beforeEach` do?
8. How do you mock a module or function in Jest?
9. How do you test asynchronous code (promises, async/await) in Jest?
10. How do you test React components with React Testing Library? What is its guiding philosophy?
11. What is the difference between `getBy`, `queryBy`, and `findBy` in RTL?
12. How do you test a custom React hook?
13. How do you mock API calls in frontend tests (msw, jest mocks)?
14. What should you test vs not test?

## Advanced

15. How do you unit test a NestJS service with mocked dependencies? (your CV: NestJS)
16. How do you write e2e tests for a NestJS API (`Test.createTestingModule`, supertest)?
17. How do you test code that uses a database (test DB, in-memory, transactions/rollback)?
18. How do you test time-dependent code (timers, debounce) with Jest fake timers?
19. How do you handle flaky tests and what causes them?
20. How would you introduce a testing culture into a codebase that has no tests? (your CV context)
21. What is TDD and what are its pros and cons?
