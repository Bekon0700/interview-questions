# Learning Tracker

> [!abstract] What this area is
> Separate from the [[../README|interview question bank]]. This is a running tracker for things you **want to learn**, are **currently learning**, or have **learned** — each linked to its own note with resources, progress log, and notes-to-self. Not interview-format Q&A.

## Callout conventions (every topic note)

| Callout | Meaning |
|---------|---------|
| `> [!tip]` | Resource — course, doc, article, video |
| `> [!note]` | Dated progress log entry |
| `> [!example]` | Worked example / exercise / code snippet |
| `> [!question]` | Open question or thing you're stuck on |
| `> [!success]` | Key takeaway once a concept clicks |

Each topic note has frontmatter: `title`, `topic: learning`, `status` (`want-to-learn` / `currently-learning` / `learned`), `started`, `tags`, `related`.

New topic → copy [[_template]].
